# kuab

vai se tratar de um projeto baseado em ollama, vamos usar a stack backend com python/fastapi, frontend em react/vite.

o foco do projeto vai ser um chatbot com interface web, para eu interagir com a IA, vou usar o ollama community para poder rodar um modelo de linguagem especifico, o modelo deve poder ler arquivos diversos de treinamento, o sistema deve poder permitir a troca rapida de modelos com um dropdown ao lado do campo de chat. vamos começar com a interface do chat e o seletor de modelos, não use nada como fallback, nenhum modelo fixo deve ser mencionado hardcoded no codigo, caso haja algum erro trate com uma mensagem e exiba no log
